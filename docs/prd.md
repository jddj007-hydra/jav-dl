# jav-dl 后续需求

下载和归档的正确性已经在 `e3e6531` 收过：aria2 会跟到真正的下载，迅雷找不到已完成任务时不再改成失败，散文件归档不会删掉 `xunlei/`、`jav-dl/`，大文件移动不再占住事件循环，失败会写日志。

这份文档只排后面的事。做完一个阶段再开下一个，不把后面的阶段提前塞进来。

## 现在的用法

一个人在局域网里用。JAV 从 JavBus 和磁力猫进队列，欧美从 ThePornDB 取元数据、磁力猫取磁链。下载器是 aria2 或群晖迅雷。下完后 JAV 进 `媒体库/YYYYMM/番号/`，欧美进片商目录。迅雷面板里直接下的欧美片，由下载目录监控归档，不经过队列。

## 不做什么

- 不做字幕翻译、演员头像、在线播放。
- 不把欧美片写进 JAV 的年月/番号目录。
- 不换掉磁力猫作为主磁链来源；备用源是补位，不是改主流程。
- 订阅默认只提醒。自动下载必须单独打开，并且带体积和标签条件。

## 阶段

### 1. 队列能管，监控不抢文件

队列里完成、失败、取消的记录只能越积越多，暂停和取消对已经结束的任务还亮着。欧美监控不看队列：它先把文件归档走，队列里那条就一直「刮削失败」。`_busy_codes` 认的 `scraping` 状态从来没人写过。

做完之后：

- 下载还没结束、或者下完但刮削还没成功的任务，JAV 监控和欧美监控都跳过它对应的文件。
- 真正开始搬文件时，刮削状态写成「正在刮削」。
- 队列可以按全部、下载中、已完成、失败、已取消筛选。
- 已结束的记录可以单条删除，也可以清空已完成、清空全部已结束。进行中的记录删不掉，要先取消。
- 刮削失败的已完成任务可以点「重新刮削」。
- 可以手动重扫媒体库，不必重启才让新放进去的片子出现在「已有」里。
- 状态用中文显示。下载失败和刮削失败分开写原因。

### 2. 收口局域网安全

现在默认不认证，并且监听所有网卡。任何人可以改迅雷地址，服务会带着已保存的面板账号去访问。封面白名单是子串匹配，还会跟着跳转。`/api/health` 不需要登录，每次对外打多路请求。证书校验默认关闭。

做完之后：

- 镜像启动时如果没设 `AUTH_USER` 和 `AUTH_PASS`，日志里明确警告。Compose 加上 healthcheck。
- 封面代理只允许主机名精确等于或结尾是已知域名，跳转后的地址也要再验一次，不把任意 `Content-Type` 原样回给浏览器。
- `/api/health` 在开了认证之后也要登录。探测失败不再每次把四个外站都打一遍可以合并成短超时，但健康检查本身还在。
- `verify_tls` 仍可关，设置页能看见当前是开还是关。默认先不改成强制开启，避免现有代理环境突然全部失败。

### 3. 媒体库能看，番号用这次详情

库表已经有了，但只用来在搜索结果上打「已有」。欧美没有这颗标记。点 JAV 磁链下载时，番号取的是输入框的当前值，搜完如果改过输入框，归档番号就会错。

做完之后：

- 有一个媒体库页，按月份看 JAV，按片商看欧美，能打开目录路径。
- 搜索和最新列表里，欧美也能显示「已有」。
- JAV 下载使用当前详情的番号，不读输入框。
- 别的工具放进媒体目录的片子，除了阶段 1 的手动重扫，保存设置时和启动时的刷新保持不变。

### 4. 设置补全，封面请求别无限涨

`scrape_settle_seconds`、`scrape_min_mb`、`WESTERN_MEDIA_DIR` 只能改环境变量。`img_cache` 没有上限。每个请求新建一个 HTTP 客户端。

做完之后：

- 这三项出现在设置页，空着保存时保留原值。
- 封面缓存超过大约 500MB 时删掉最旧的文件。
- 查站和封面代理各复用一个客户端，而不是每个请求新建。

### 5. 磁链结果记住，域名挂了能换

磁力猫只有一个搜索域，域名一变搜索就空。每次点开番号都重新搜。

做完之后：

- 同一个番号或同一组欧美关键词，短时间内直接用上次的磁链结果。
- 设置里可以填一个备用搜索域。主域失败或结果为空时再试备用域。
- 不新增一套排序规则。

### 6. 一次贴多个番号

做完之后：

- 可以贴一串番号，先预览每个番号会入队的那条磁链（沿用现在的排序，取第一条）。
- 确认后才入队。某个番号没有磁链就跳过并标出来，不挡其他番号。

### 7. 多文件种子少下广告和样片

现在整包都下，事后只删 `manko.fun*`。

做完之后：

- 入队前能看到文件列表。默认去掉明显的广告、样片和很小的非视频文件，用户可以改勾选。
- aria2 用 `select-file`，迅雷用 `sub_file_index`。
- 只有一个文件的种子保持现在的行为。

### 8. 下完能通知

做完之后：

- 设置里可选 Telegram、Bark、Server 酱之一，也可以不通知。
- 下载完成和归档完成各发一条，失败也发一条，带番号或片名和原因。
- 通知失败只写日志，不影响下载和归档。

### 9. 追更

做完之后：

- 可以关注女优、系列、片商或欧美演员、片商。
- 定时拉 JavBus 或 ThePornDB 的新作。默认只在队列或通知里提醒。
- 打开自动下载后，才按规则入队：例如只要无码破解或中字，并且体积不超过设定值。
- 已经在库里或已经在队列里的不重复下。

### 10. 用推送代替两秒轮询

做完之后：

- 队列页用 SSE 收状态变化。页面在后台时不维持连接。
- 后台同步仍在，但前端不再每 2 秒打一轮 `list_public`。
- SSE 断了就重连；重连失败时退回偶尔拉一次，而不是每 2 秒。

## 验收

每个阶段合并前跑 `.venv/bin/python -m pytest`。改了页面的阶段，要在浏览器里把该阶段的按钮点一遍：筛选、删除、清空、重新刮削、重扫，以及空列表和失败原因。
